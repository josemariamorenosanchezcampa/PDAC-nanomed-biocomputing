# Release notes — v4.0.0

Version 4.0.0 is a structural scientific release. It replaces illustrative sensitivity/control elements with executable analysis, connects transport parameters to response, adds spatial and temporal dynamics, formalizes calibration versus external validation, and documents a human-data pathway. The release remains a computational proof of concept. Its most important next milestone is independent calibration/validation using well-defined experimental and human-derived measurements, followed by model revision where the data contradict current assumptions.
